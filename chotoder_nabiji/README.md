# ছোটদের নবীজী ﷺ

শিশুরা যেন রাসুলুল্লাহ ﷺ-কে **চিনতে**, **জানতে** এবং নিজের চেয়েও বেশি **ভালোবাসতে** পারে, সেই লক্ষ্যে তৈরি একটি Flutter অ্যাপ (Google Play Store-এর জন্য)।

## যা আছে (সংস্করণ ১.০, MVP)

| মডিউল | বিবরণ |
|---|---|
| 📖 নবীজীর গল্প | জন্ম থেকে বিদায় পর্যন্ত ১৪টি গল্প। বয়স অনুযায়ী ছোট বা বিস্তারিত সংস্করণ, "আজকের শিক্ষা", সূত্র ও কুইজ |
| 💚 নবীজী কেমন ছিলেন | শামায়েলের ১২টি কার্ড (শুধু লেখা, কোনো চিত্রায়ণ নেই) |
| 🌱 সুন্নাহ বাগান | ১২টি দৈনিক সুন্নাহ। প্রতিটি পালনে বাগানে ফুল ফোটে, টানা কত দিন পালন হলো তা দেখায় |
| 🤲 দরুদ ও দোয়া | দরুদ কাউন্টার, আরবি, উচ্চারণ ও অর্থসহ ১২টি দোয়া |
| 🌳 নবীজীর পরিবার | পিতা-মাতা, উম্মাহাতুল মুমিনীন, সন্তান, নাতি-নাতনি, সাহাবি |
| ✉️ ভালোবাসার চিঠি | নবীজী ﷺ-কে নিয়ে শিশুর মনের কথা লেখা |
| 👪 অভিভাবক কর্নার | গণিত-গেট দিয়ে সুরক্ষিত। অগ্রগতি, বয়স পরিবর্তন, বিরতির রিমাইন্ডার, আলোচনার প্রশ্ন |
| 🔊 শুনুন | ফোনের বাংলা TTS দিয়ে পড়ে শোনানো (পরে রেকর্ড করা কণ্ঠ দিয়ে বদলানো হবে) |

**নীতিমালা:** কোনো চিত্রায়ণ নেই, বাদ্যযন্ত্র নেই, বিজ্ঞাপন নেই, ব্যক্তিগত তথ্য সংগ্রহ নেই, সম্পূর্ণ অফলাইন।

## ⚠️ প্রকাশের আগে আলেম রিভিউ বাধ্যতামূলক
`assets/data/*.json`-এর সব কনটেন্ট সহীহ উৎস থেকে সূত্রসহ খসড়া করা হয়েছে। তবুও Play Store-এ প্রকাশের আগে **যোগ্য আলেম দিয়ে প্রতিটি গল্প, হাদিস নম্বর, আরবি টেক্সট ও উচ্চারণ যাচাই** করিয়ে নিন।

## কনটেন্ট যোগ/সম্পাদনা
কোড না ছুঁয়েই `assets/data/` ফোল্ডারের JSON ফাইলে নতুন গল্প, দোয়া বা সুন্নাহ যোগ করা যায়:
- `stories.json` – গল্প (`short` অংশটি ৩–৬ বছরের শিশুদের জন্য, `paragraphs` বড়দের জন্য, `quiz`-এর `answer` হলো সঠিক অপশনের সূচক, যা ০ থেকে শুরু হয়)
- `shamail.json`, `duas.json`, `sunnah.json`, `family.json`

## ডেভেলপমেন্ট
```bash
cd chotoder_nabiji
flutter pub get
flutter test            # কনটেন্ট যাচাই + স্টেট + UI টেস্ট

```

## APK / Play Store বিল্ড
- প্রতিবার push করলে GitHub Actions (`.github/workflows/android.yml`) টেস্ট চালায় এবং **APK ও AAB** তৈরি করে। Actions ট্যাবে গিয়ে Artifacts থেকে ডাউনলোড করুন।
- Play Store-এর জন্য নিজের আপলোড কী তৈরি করুন:
  ```bash
  keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
  ```
  তারপর রিপোজিটরির Secrets-এ যোগ করুন: `ANDROID_KEYSTORE_BASE64` (`base64 -w0 upload-keystore.jks`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`। কী ফাইল কখনো কমিট করবেন না।
- প্যাকেজ নাম: `org.chotodernabiji.app` (প্রথম আপলোডের আগে চাইলে `android/app/build.gradle.kts`-এ বদলান, পরে আর বদলানো যায় না)।
